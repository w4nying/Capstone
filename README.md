# 📊 Dashboard

A dashboard application built using **React Admin**.


## 🚀 Getting Started

Follow the steps below to run the project locally.


## 📦 Prerequisites

Ensure you have the following installed:
1. **Node.js** (v16 or later recommended)

Go to smart-dashboard directory
```bash
cd smart-dashboard
```

Install npm
```bash
npm install --save-dev concurrently
```

Run Database Server and Development Server
```bash
npm start
```

APIs will be available at:  

Database API:  
```bash
http://localhost:3000
```  
React Application:  
```bash
http://localhost:5173
```  


## 🧭 Notes

- Start the mock database server **before** running the development server
- Default Vite port is `5173` unless configured otherwise
